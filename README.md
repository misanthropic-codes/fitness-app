# fitness-app

React Native (Expo) client for the health & lifestyle intelligence app.

## Setup

```bash
npm install
npm start
```

Then open in Expo Go (iOS/Android) or press `i` / `a` / `w`.

## Stack

- Expo SDK 58 + TypeScript
- Expo Router (`app/`)
- Local-first logging / API sync come next (see product docs)
